# HZ TECH

A responsive, static React portfolio website for web development and DevOps services.

## Stack
- React
- Vite
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Customization
Update the email and WhatsApp placeholders in `src/components/Contact.jsx`.
Edit services in `src/data/services.js` and showcase examples in `src/data/showcase.js`.
